# Changelog

## [1.3.0] - 2026-08-23

### Added

- **Keyboard GIF copying** - Copy the currently selected GIF as Markdown with the platform's standard copy shortcut.
- **Accessible result navigation** - Expose the active GIF result to assistive technology during keyboard navigation.
- **Command Palette access** - Open the GIF picker from Roam's Command Palette and insert at the current block and cursor position.

### Changed

- **Roam-native picker styling** - Match the GIF picker surface to Roam's native search modal styling.
- **Keyboard command footer** - Match Roam's native gray command footer with labeled keyboard shortcut chips.
- **Stable search loading** - Keep the results viewport stable while searches load and show Blueprint skeleton previews.
